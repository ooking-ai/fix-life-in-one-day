# 一天重塑人生 · 精读学习指南

Fix Your Life in One Day — Bilingual Study Guide for English Learners

基于 Dan Koe 在 X 上发表的长文《How to fix your entire life in 1 day》（2026-01-13）制作的**精读学习指南**，不是原文转载。

原文：https://x.com/thedankoe/status/2010751592346030461

## 这是什么

- 7 章概括：用更简单的英文重新讲述每个核心观点，配中文翻译
- 重点词汇短语：28 个词，点击展开释义、音标、例句，点 🔊 可听发音
- 插图：纯 CSS / SVG 手绘概念图（身份循环、控制论循环、九层心智、一日时间线、游戏地图）
- 互动：中英对照 / 纯英文 / 仅中文切换、字号、深色 / 米色主题、阅读进度条、章节打勾
- 练习：词汇闪卡（翻卡）、6 道小测验、一日行动手册（答案只保存在浏览器本地，可下载 .txt）

## 技术

纯 `index.html` 一个文件：HTML + CSS + JavaScript，无外部依赖、无追踪、无外部图片，现代浏览器直接打开即可。

## 本地预览

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000/
```
